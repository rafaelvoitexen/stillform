# STILLFORM

STILLFORM is a personal creative front-end project I made for my portfolio.

I wanted to experiment with a more cinematic kind of website, using architectural photography, bold typography, and motion to explore the idea of negative space.

It's a small creative playground where I could push my skills with **GSAP**, scroll-based animations, and interactive, responsive layouts. There's no client behind it; it's simply something I wanted to design and build.

**Built with:** Astro · TypeScript · GSAP / ScrollTrigger · Lenis · CSS
